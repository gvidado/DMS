# 数据判读系统 V0.10.12 更新说明

序列Excel读取和转换小工具适配十一列新格式，兼容原标准七列格式。

| 新表来源列 | 转换后的七列表 |
| --- | --- |
| A 关键字 | A 关键字 |
| B 测试工作内容 | B 测试工作程序内容及要求 |
| C 指令 | C 指令或参数 |
| D 判读 | D 判读要求 |
| F 标志 | E 标志 |
| G 期望执行时间 | F 期望执行时间 |
| H 超时 | G 超时时间 |

E、I、J、K完全不参与数据读取、指令识别、判据、时间校验和导出。仅这些列有内容的行不作为序列项。被保留的步骤继续保留原始Excel行号。

按各Sheet的表头自动识别七列或十一列布局，同一文件可包含两种格式。支持“测试工作内容”和原“测试工作程序内容及要求”等表头名称，“判读/判读要求”“超时/超时时间”均可识别。

小工具继续沿用当前已确认的库内指令优先、说明列补救、TEXT处理、控制行保护和PLUSE逻辑。忽略列中的指令文字不会被用于匹配。有效列的公式或错误仍在预览中显示，并可修改后重新检测。

转换导出包含所有已读取工作表，固定输出七列A～G。文件名仍为“原文件名_判读格式匹配.xlsx”。仅预览和导出不会保存或执行序列。

升级包保留现有配置与数据。停止程序后完整覆盖升级包，重新启动并按Ctrl+F5刷新网页，确认版本为0.10.12。另提供默认配置和数据均已清空的干净离线包，新目录部署使用。
