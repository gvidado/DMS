# V1.0.0 更新说明

## PostgreSQL 历史库

- 恢复独立的「历史查询」网页和「系统配置 → 历史存储配置」。采集对象包括接收 UDP/SPP 原包与校验情况、解码参数、发送与监视到的指令及采集会话。判读结果继续保存在现有文件存档中。
- 原包和样本先异步落入本地压缩分段，后台批量写入 PostgreSQL。断开数据库连接期间仍可归档，恢复连接后按记录标识补写。历史数据永久保留，容量与补写状态可在网页查看。
- 现场在线数据按服务器接收、发送或捕获时刻统一排序，参数与对应 SPP 包共享时间。页面、筛选与常规导出显示北京时间。导入 pcapng 保留文件原始时间。
- 支持按试验、参数、SPP 包和指令多选查询，查看原始 UDP 载荷。参数历史可按同一 SPP 包一行导出 Excel，数据底座可导出全量 JSONL 及原始文件。

## 启用

升级覆盖程序文件，保留 `config`、`data`、`logs`、独立归档目录和原 PostgreSQL 库。既有历史连接配置可沿用，换电脑或 Windows 账号后重新填写数据库密码。无需清空或重建已有库。

新部署默认关闭采集及写入。已有独立历史库时，直接在「历史存储配置」填写连接。尚未建库时，在同机安装并启动 PostgreSQL 后，在程序目录用 PowerShell 运行以下命令。安装位置不同时替换 `-PgBin` 路径。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\tools\初始化历史数据库.ps1" -PgBin "C:\Program Files\PostgreSQL\18\bin" -Port 5432
```

在「历史存储配置」填写数据库、专用账号、密码和归档目录，例如 `D:\TelemetryHistory`。勾选「启用全量历史采集与归档」和「启用数据库写入与补写」，保存后用「检查并初始化历史表」核对连接。停止监听时保存立即生效，监听运行时按 120 秒的配置周期生效。
